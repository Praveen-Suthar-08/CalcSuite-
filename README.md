# CalcSuite

A polished, responsive static Calculator Suite for GitHub Pages.

## Included

- Basic calculator with keyboard support and persistent history
- Scientific calculator
- BMI calculator
- Unit converter
- Currency converter with live-rate attempt and fallback rates
- Age calculator
- Date difference / add-subtract calculator
- Dark/light mode

## Tech

HTML5, CSS3 and vanilla JavaScript. No backend required.

## GitHub Pages

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

The currency converter attempts the public Frankfurter exchange-rate endpoint and falls back to built-in reference rates if unavailable.
